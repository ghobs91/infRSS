# XML Parsing Error Fix

## Problem
RSS feeds from various sources (e.g., Railway Age, and other publishers) were failing to parse with errors like:

```
XML parsing error for https://www.railwayage.com/category/passenger/rapid-transit/feed/: 
This page contains the following errors:
error on line 1450 at column 1: CData section not finished
><![CDATA[>><![CDATA[><![CDATA[>>
```

## Root Cause
The RSS feeds contained malformed CDATA sections with patterns like:
- `><![CDATA[>>` - CDATA start without proper content
- `><![CDATA[><![CDATA[>>` - Double nested malformed CDATA
- `><![CDATA[><![CDATA[><![CDATA[>>` - Triple nested malformed CDATA

These patterns are generated by poorly configured XML/RSS generators that don't properly escape or wrap content.

## Solution
Enhanced the `cleanXMLContent()` function in `/src/lib/rssUtils.ts` with a multi-step approach:

### Step 1: Remove Malformed CDATA Patterns
Before any other processing, we now remove the specific malformed patterns in order from most specific to least specific:

```typescript
// Triple nested (most specific first)
xmlString = xmlString.replace(/><!\[CDATA\[><!\[CDATA\[><!\[CDATA\[>>/g, '>');

// Double nested
xmlString = xmlString.replace(/><!\[CDATA\[><!\[CDATA\[>>/g, '>');

// Single malformed with extra >
xmlString = xmlString.replace(/><!\[CDATA\[>>/g, '>');

// Incomplete CDATA start
xmlString = xmlString.replace(/><!\[CDATA\[>/g, '>');
```

### Step 2: Remove Invalid XML Characters
Strip control characters that aren't allowed in XML (except Tab, LF, CR).

### Step 3: Fix Unclosed CDATA Sections
Detect and close any CDATA sections that are missing their closing `]]>` tags.

### Step 4: Escape Problematic Sequences
Handle CDATA sections that contain `]]` sequences by properly escaping them.

### Fallback Strategy
If parsing still fails after cleaning, the code now:

1. **Strips all CDATA** - Removes all CDATA markers entirely and re-escapes content
2. **Manual item extraction** - Extracts individual `<item>` or `<entry>` elements and reconstructs a minimal valid RSS feed
3. **Returns null gracefully** - If all strategies fail, returns null instead of crashing

## Benefits
- ✅ Feeds that previously failed now parse successfully
- ✅ More robust error handling with multiple fallback strategies
- ✅ Better logging for debugging malformed feeds
- ✅ Graceful degradation instead of crashes

## Testing
To verify the fix is working:

1. Add a problematic feed URL (like the Railway Age feed)
2. Check the browser console for parsing logs
3. Confirm that articles are now loading from previously failing feeds

## Prevention
While we can't fix the source feeds, this solution makes the RSS reader resilient to common XML malformations found in real-world feeds.
